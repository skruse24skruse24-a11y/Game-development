# 2D Game Template – Godot 4

A clean starting point for 2D game development using [Godot 4](https://godotengine.org/).

## Getting Started

1. **Install Godot 4** – download from <https://godotengine.org/download>.
2. **Open the project** – launch Godot, click *Import*, and select the `project.godot` file in this folder.
3. Start building — the editor opens to a blank `Main` scene ready for your nodes and scripts.

## Project Structure

```
.
├── project.godot   # Godot project configuration
├── icon.svg        # Project icon
└── scenes/
    └── Main.tscn   # Blank Node2D scene (start here)
```
